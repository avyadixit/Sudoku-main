# AI-Based Sudoku Recognition and Solver

##  Overview
This project is an AI-based system that detects and solves Sudoku puzzles from images using Computer Vision and Machine Learning techniques.

##  Features
- Detects Sudoku grid from image
- Recognizes digits using CNN model
- Solves Sudoku using backtracking algorithm
- Displays solution on original image

##  Technologies Used
- Python
- OpenCV
- TensorFlow / Keras
- NumPy

##  How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python Main.py

## 📸Output
- Input image → Recognized grid → Solved output
